# Syndicate

**SaaS de prospecção de clientes (n8n).**

Sistema de prospecção de clientes para a agência WebInclude.

## O que é

O Syndicate encontra comércios de uma região, olha a presença digital de cada um e aponta
**qual serviço da agência faz sentido oferecer** para aquele cliente. Assim o vendedor chega
no contato já sabendo o que propor.

**Fluxo:** encontrar o comércio → analisar a presença digital → recomendar o serviço →
priorizar → contatar.

**Serviços que a agência vende:** landing pages, criação e reforma de sites, e-commerce,
social media, tráfego pago e SEO.

## Situação

**Recomeçando do zero (07/10/2026).** A primeira versão (Laravel 13 + Filament 5, com
busca no Google Places, análise de site, PageSpeed, laudo em PDF e controle de custo)
foi descartada por estar complexa demais. A nova versão será **mais simples**.

O escopo e a stack da nova versão ainda serão definidos.
